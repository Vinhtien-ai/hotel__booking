HUONG DAN CAP NHAT DATABASE VA KIEM THU HOTELBOOKING

1. Mo Web.config va kiem tra connectionStrings, xac dinh dung SQL Server/database dang duoc project su dung.
2. Mo SQL Server Management Studio, ket noi dung SQL Server.
3. Chon dung database theo connection string.
4. Mo file SQL_Update_BookingStatus.sql va Execute.
   Script chi them cot dbo.Booking.Status neu chua co, mac dinh N'Da dat' cho cac don cu.
   Script khong xoa du lieu Booking.
5. Trong Visual Studio: Clean Solution, Rebuild Solution, chay website.

LUONG CUSTOMER:
- Menu Dat phong -> Room/Index (chon phong).
- Chon Xem phong -> Room/Details.
- Dat phong ngay -> Cart/AddToCart (POST), sau do vao Cart/Index.
- Menu Gio dat phong -> Cart/Index.
- Xac nhan dat phong -> Booking/SubmitBooking.
- Lich su dat phong -> Booking/History.

LUONG ADMIN:
- Quan ly Booking -> Booking/Index -> Booking/History.
- Cap nhat trang thai su dung Booking/UpdateStatus.
- Quan ly phong su dung HotelRooms (mot dau moi menu: Danh sach phong).
- Quan ly loai phong chi hien thi cho Admin.

LUU Y:
- Neu Booking/History van bao Invalid column name 'Status', database ma Web.config dang ket noi chua duoc chay script.
- Neu van loi khac, can lay nguyen van exception va InnerException de doi chieu.
- Khong tu dong sua database tu code; nguoi quan tri phai chay script tren dung database.
